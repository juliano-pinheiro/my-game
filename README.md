# 🐤 Flying Bird - Retro Edition

Uma recriação moderna, estilizada e independente do clássico gênero arcade, desenvolvida com o nome **Flying Bird** inteiramente em **HTML5**, **Canvas 2D** e **Vanilla JavaScript**.

---

## 🚀 Como Jogar

Você não precisa instalar nenhum programa, dependência ou servidor!

1. Basta dar um duplo clique no arquivo **`index.html`** para abrir no seu navegador preferido (Google Chrome, Microsoft Edge, Firefox, etc.).
2. Ou arraste o arquivo `index.html` para uma aba aberta do seu navegador.

---

## 🎮 Controles

| Ação | Teclado | Mouse / Touchscreen |
| :--- | :--- | :--- |
| **Bater asas / Pular** | <kbd>Espaço</kbd>, <kbd>Seta para Cima</kbd> ou <kbd>W</kbd> | Clique esquerdo ou Toque na tela |
| **Trocar Skin** *(Antes de iniciar)* | <kbd>S</kbd> | Botão de óculos 🕶️ (topo) ou badge na tela inicial |
| **Pausar / Despausar** | <kbd>P</kbd> | Botão de pausa ⏸️ (topo direito) |
| **Ativar / Desativar Som**| — | Botão de alto-falante 🔊 (topo esquerdo) |
| **Reiniciar após Game Over** | <kbd>Espaço</kbd> ou <kbd>Seta para Cima</kbd> | Clique ou Toque na tela |

---

## 🎨 Skins Modernas Inclusas

Pressione <kbd>S</kbd> ou clique no botão/badge para alternar entre as 4 skins exclusivas:

1. 🕶️ **Aviador Moderno (Padrão):** Pássaro aventureiro com óculos de aviador de lentes brilhantes na testa, topete aerodinâmico, bochechas rosadas, olhos expressivos modernos e penas estilizadas.
2. ⚡ **Cyberpunk Neon:** Chassi grafite/metálico com iluminação futurista ciano, propulsor traseiro e visor holográfico com brilho neon.
3. 🔥 **Fênix Mística:** Plumagem radiante com gradiente de chamas, três plumas ardentes na crista e asas de fogo.
4. 🐥 **Clássico HD:** Remasterização suave do design tradicional com sombreamento esférico 3D, asas em relevo e reflexo nos olhos.

---

## ✨ Recursos Implementados

* **Áudio 100% Sintetizado em Tempo Real:** Utiliza a *Web Audio API* nativa do navegador para gerar efeitos retrô autênticos (bater asas, pontuação, batida e queda), sem depender de arquivos `.mp3` externos.
* **Física Fluida e Rastro de Velocidade:** Gravidade calibrada, rotação dinâmica e partículas aerodinâmicas personalizadas com a cor da skin ao bater asas ou planar.
* **Cenário em Parallax:** Nuvens em movimento, silhueta de cidade e chão listrado com grama verde.
* **Efeitos Visuais de Impacto:** Tremor de tela (*screen shake*), clarão (*screen flash*) e explosão de penas e partículas ao colidir.
* **Sistema de Medalhas:**
  * 🔒 Pedestal com Cadeado (< 3 pontos com meta clara)
  * 🥉 Bronze (≥ 3 pontos)
  * 🥈 Prata (≥ 10 pontos)
  * 🥇 Ouro (≥ 20 pontos)
  * 💎 Platina (≥ 30 pontos)
* **Persistência de Recorde e Preferências:** O seu melhor resultado (*Best Score*), skin favorita e a preferência de áudio são salvos automaticamente no `localStorage` do navegador.
* **Totalmente Responsivo:** Funciona e escala perfeitamente em telas de computadores, notebooks, tablets e smartphones.

## 🌐 Publicar no GitHub Pages

O projeto já está 100% pronto para ser hospedado no GitHub Pages com suporte tanto para a raiz `/` quanto para a pasta `/docs`, além de workflow automático em GitHub Actions.

Para ver o passo a passo detalhado de como subir para o GitHub e ativar o Pages, consulte o arquivo [**`DEPLOY.md`**](DEPLOY.md).

```bash

git add .
git commit -m "feat: Flying Bird game ready for GitHub Pages"
git remote add origin https://github.com/<seu-usuario>/<seu-repositorio>.git
git push -u origin main
```
